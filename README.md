# Isabelinha — Montra Digital

Site simples para a Pastelaria Isabelinha mostrar a **ementa do dia** e as
**reservas de Natal** num ecrã na loja.

A ementa é escrita num Google Sheets e aparece automaticamente no site,
sem precisar de mexer no código.

## Ficheiros
- `index.html` — página principal, com os botões para a ementa e para o Natal
- `ementa.html` — ementa do dia
- `natal.html` — reservas de Natal

Feito com HTML, CSS e JavaScript. Alojado no GitHub Pages.
